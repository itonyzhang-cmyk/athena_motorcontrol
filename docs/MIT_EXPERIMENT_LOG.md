# MIT 五参数实验台账

本文件记录每次实际涉及电机运动的实验。任何结论必须绑定到完整的
`固件 SHA + 源提交/工作区状态 + 目标 + 参数 + 日期 + 结果`，不得用“当前版本”
等模糊名称替代。实验镜像默认不能进入 WebUI 正式配置。

## 实验生命周期

- **进行中**：允许在限定参数和限定机械范围内重复测试。
- **放弃**：出现明确失败、不可复现，或被更新实验替代；保留产物和失败证据，
  不再作为默认刷写目标。
- **候选晋级**：目标已在同一镜像上重复通过，且没有新增安全、CAN、校准、
  位置或速度回归；仍需在干净提交中重建。
- **合并主库**：仅限候选晋级后，将经过审查的最小源码差异提交到正式分支，
  使用干净工作区构建，并重新完成刷写、校准、MIT/轨迹和停机回归。

## 目标复核与版本审计（2026-09-06）

- 当前目标没有偏移：在同一已刷写的 v8 实验镜像上，验证 MIT 五参数的电机侧
  位置、速度、前馈力矩和停机语义；WebUI 只负责输出端 P/V 到电机侧的 `9:1`

  结果合并。实验镜像不能直接成为正式固件，晋级前必须在干净提交重建并复验。

### MIT-20260906-B：v8 位置参数复测与速度边界

- 日期/设备：2026-09-06，`192.168.31.20`，UID `39305137-14303434-47457A29`。
- 固件：`artifacts/athena_config_commit_async_v8_20260905/motorcontrol.bin`，
  SHA-256 `e640fd1f1fa5bdee1a86b3c4d6b9a9d1ef4ac64832d54b3318aa42f2ee53c077`。
- 源：`experiment/current-loop-pi-measurement`，HEAD `5360904c`，实验脏工作区；
  固件 provenance 在对应 artifact 中，不能作为正式发布来源。
- 参数：位置候选 `Kp=10/Kd=0.5/重力=0/摩擦幅值=0.3 Nm`；速度边界
  `Kp=0/Kd=0.5`，摩擦幅值分别 `0.3/0.6 Nm`。
- 位置结果：输出端 `+/-0.06 rad` 小步长和约 `+/-1.08 rad` 电机侧大步长均方向
  正确。大步长目标 `6.6996 rad` 的正向最终误差约 `0.0006 rad`，目标 `5.6196 rad`
  的反向最终误差约 `0.0003 rad`；小步长最差停机后误差约 `0.022 rad`。四次会话
  252/352 帧，最大间隔 `28.7..29.9 ms`，均显式发送 `0xFD`，无故障。
- 速度结果：摩擦 `0.3 Nm`、输出端 `+/-0.02 rad/s` 只能产生小幅响应；摩擦
  `0.6 Nm`、输出端 `+/-0.1 rad/s` 可连续正反向运动，约为 `5.70 -> 8.78 -> 5.51`
  电机侧。说明瓶颈是静摩擦/速度模式的力矩阈值与无位置锚定语义，不是 CAN 节拍。
- 追加边界：`Kd=1`、摩擦 `0.3 Nm`、输出端 `+0.05 rad/s` 运行 3 s 时反馈范围
  扩大到 `4.02..8.19 rad`、峰值力矩约 `1.61 Nm`，判定为速度模式不稳定；随后
  用位置候选参数恢复到目标 `3.0213 rad`，最终 `3.0228 rad`，未出现位置环回归。
- 状态：**位置候选晋级（仅限 v8 实验镜像）**；**速度模式进行中**，`0.6 Nm`
  不作为默认值，需单独定义恒速误差、加减速和停机验收指标。
- 详细结果：`artifacts/athena_mit_v8_20260906/RESULTS.md`。
